# 信贷产品介绍

## 随心贷（消费贷）

- 定位：个人日常消费（购物、装修、教育、医疗、旅游等）
- 额度：1,000 元 ~ 500,000 元
- 期限：3 ~ 60 个月
- 年化利率：5.95% 起（1年期LPR + 信用等级加点，A级客户最低）
- 还款方式：等额本息
- 放款速度：自动审批通过后即时放款
- 申请渠道：APP / H5 / API网关 / 渠道合作方 / 线下网点

## 生意贷（经营贷）

- 定位：小微企业与个体工商户经营周转
- 额度：上限 500,000 元
- 期限：3 ~ 60 个月
- 年化利率：按信用等级定价（见利率说明）
- 特殊要求：须提供营业执照并完成经营场所核验；放款前签署电子借款合同
- 资金用途：仅限生产经营，不得流入房产、股市等监管禁止领域

## 产品共同特点

- 全程线上自动审批：受理 → 进件审核 → 反欺诈 → 信用评估 → 审批决策 → 合规审计 → 贷后管理，秒级完成
- 三层决策保障：大模型智能推理 + 规则引擎 + 保守兜底（转人工），宁可误杀不可误放行
- 资金用途合规监管：禁止用于股票、期货、购房首付、赌博等（命中即一票否决）
- 利率合规：不超过 4 倍 LPR 司法保护上限与 24% 上限
- 个人信息保护：全流程遵循《个人信息保护法》（PIPL），征信查询须经本人授权
